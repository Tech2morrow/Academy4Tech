# Learning visual asset guide

The 16 subject illustrations were created with Codex's built-in image generation tool, then exported as optimized JPEG assets for fast page loading. The original full-resolution PNG generations remain in the local Codex generation history.

## Shared generation brief

Create a scientifically educational, technically plausible 16:9 illustration for secondary-school students. Use a friendly isometric 3D style on a warm cream background with orange, teal and violet accents. Keep the composition clear, bright and approachable. Show the system's important parts and relationships visually. Do not include text, logos, watermarks, a dark theme or decorative clutter.
